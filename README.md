# Netflix Data Analysis Dashboard  

This repository showcases an interactive **Power BI Dashboard** that provides insights into Netflix's movie and TV show data. The project is a visual representation of key trends and patterns, designed for data exploration and analysis.

---

## 🚀 **Features**

- **Dynamic Filters**: Analyze data by rating, genre, actor, director, and country.  
- **Visual Trends**:
  - Movies and TV shows by rating.
  - Country-wise distribution of content.
  - Count of releases over the years.  
- **Geographic Insights**: Interactive map showing the distribution of Netflix content.  
- **Interactive Visualization**: User-friendly interface for detailed exploration.  

---

## 🛠 **Tools Used**

- **Power BI**: For creating interactive visualizations.  
- **Data Sources**: Netflix movie and TV show dataset.  
- **Excel**: Data cleaning and preprocessing.
